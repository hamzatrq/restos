# @restos/auditor

**Owning spec: `specs/20-testing-correctness.md §4.2` — read it before modifying anything here (AGENTS.md routing).**

- `runAuditor` — the READ-ONLY nightly refold of ONE org's kernel ledger, and `20 §4.2`'s *"single highest-value correctness artifact we build"*. Five legs: lamport gaps, money conservation, state legality, the audit hash-chain, unparseable merged events (+ the read-model diff leg, whose input nothing supplies yet — see the `@unreached-owed` marker in `src/auditor.ts`).
- **`01-F1`: it writes NOTHING, ever.** Only `select` statements exist in `src/auditor.ts` and its host issues one more (the org list). A write laundered through the one component documented to write nothing is a review rejection, not a discussion.
- **Fold logic is NEVER reimplemented here.** The refold uses the REAL engine through `@restos/sync-client/fold-engine` — the pure subpath, which `services/sync-gateway`'s `auditor-purity.test.ts` pins as a spawned-node import-graph test (no `better-sqlite3` in the graph). Legality, money residuals and chain verification delegate to `@restos/domain`.
- **Why this is a package and not a file in the gateway: `DEC-ARCH-001` (RULED, founder, August 2026).** It was written inside `services/sync-gateway` and moved here unchanged when it acquired a second consumer, which is `18 §2`'s own rule for that event; `services → services` is on none of that section's allowed edges. Two consumers today: `services/jobs` (the scheduled host, importing `@restos/auditor`) and `services/sync-gateway` (whose barrel re-exports every name).
- **It has no suite of its own, by design.** The Auditor's behaviour is owned by the ten `auditor-*.test.ts` suites in `services/sync-gateway/src/__acceptance__/`, which reach it through that service's barrel, plus `services/jobs`' `auditor-package-move.test.ts` §G over the production specifier. `DEC-ARCH-001` is a pure move: no test moved with it, and none should be duplicated here.
- **`packages → services` is the inversion to watch.** The db handle is `AuditorDb`, declared locally; importing the gateway's `GatewayDb` type instead compiles, links and runs while inverting `18 §2` outright.
